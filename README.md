# ⚡ Zepto Sales and Delivery Performance Analysis

An end-to-end Exploratory Data Analysis (EDA) and automated visualization project evaluating product category revenue, city-level market demand, order fulfillment success, and top SKUs for **Zepto** using Python (`Pandas`, `Matplotlib`, `Seaborn`).

---

## 📂 Repository Structure

| File / Folder | Description |
| :--- | :--- |
| `01_zepto_products.csv` | Master product catalog (38 products across 6 categories with `base_price`). |
| `02_zepto_sales.csv` | Raw transactional dataset (220,220 sales records across 8 cities). |
| `03_zepto_sales_cleaned.csv` | Cleaned and imputed sales dataset generated by the pipeline. |
| `04_zepto_analysis.py` | Master Python script handling data cleaning, merging, and chart generation. |
| `05_charts.pdf` | Comprehensive multi-page visual report containing all charts and key business insights. |

---

## 🛠️ Data Cleaning & Engineering Workflow
1. **Deduplication:** Dropped 220 fully duplicated rows, streamlining the dataset from 220,220 to 220,000 records.
2. **Missing Value Imputation:**
   - Categorical nulls (`city`, `delivery_status`) were designated as `"Unknown"`.
   - Missing `delivery_time_mins` records were imputed using **city-specific median delivery times** to preserve local logistics behavior.
3. **Table Merging & Revenue Metric:** Joined sales logs with product metadata on `product_id` and calculated realized revenue as `quantity x base_price` (normalized in INR Millions).
4. **Revenue Filtering:** Filtered revenue-based aggregations to include only `Delivered` orders with a known city, preventing cancelled/returned orders from distorting performance metrics.
